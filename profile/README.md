**Repo Livre** reúne projetos open source testados e explicados: o que cada um faz, a licença e se vale a pena usar. Também é onde ficam os projetos abertos da [Irondes](https://github.com/irondes).

## O que você encontra aqui

- **`{meus projetos}`:** ferramentas que eu criei e abri para quem quiser usar, estudar ou fazer fork.
- **`{achados}`:** projetos open source de outras pessoas que eu testei, com a licença, para que servem e o meu veredito.
